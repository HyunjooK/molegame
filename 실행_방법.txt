🚀 한글 두더지 잡기 게임 - 자동 배포 실행 방법

===========================================
방법 1: PowerShell에서 실행 (권장)
===========================================

1. '자동_배포.ps1' 파일 우클릭

2. 'PowerShell에서 실행' 선택
   (또는 'PowerShell로 열기' 선택)

3. 만약 실행이 안 되면:
   - PowerShell을 관리자 권한으로 실행
   - 다음 명령어 입력:
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   - Y 입력하여 확인
   - 다시 '자동_배포.ps1' 실행


===========================================
방법 2: PowerShell 직접 사용
===========================================

1. 이 폴더에서 Shift + 우클릭

2. 'PowerShell 창 여기에 열기' 선택

3. 다음 명령어 입력:
   .\자동_배포.ps1

4. Enter 키 누르기


===========================================
스크립트가 하는 일
===========================================

✅ Git 설치 확인
✅ Git 사용자 설정
✅ Git 저장소 초기화
✅ 파일 추가 및 커밋
✅ GitHub에 업로드

GitHub 로그인만 하시면 자동으로 배포됩니다!


===========================================
배포 후 할 일
===========================================

1. https://github.com/HyunjooK/molegame 접속

2. Settings → Pages 클릭

3. Source를 "GitHub Actions"로 변경

4. 1-2분 대기

5. 완료! 게임 주소:
   https://HyunjooK.github.io/molegame/


===========================================
문제가 생겼나요?
===========================================

Git이 설치되지 않았다는 메시지가 나오면:
→ https://git-scm.com/downloads 에서 Git 다운로드
→ 설치 후 컴퓨터 재시작
→ 스크립트 다시 실행

권한 오류가 나오면:
→ PowerShell을 관리자 권한으로 실행
→ Set-ExecutionPolicy RemoteSigned 실행

GitHub 로그인이 안 되면:
→ 웹 브라우저에서 먼저 GitHub에 로그인
→ 스크립트 실행 시 로그인 창에서 승인
